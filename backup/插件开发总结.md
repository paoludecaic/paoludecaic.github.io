## GmeekButton-Top-Foot

两个插件实现的功能是一样的，唯一区别就是排列方式，所以禁止一起加载这两个插件


> [!TIP]
> GmeekButton-Top-Foot-row

# 插件整合

由于配置文件 `config.json` 关于 `script` 键多插件引用的问题过于臃肿，本人又另外写了一个 `插件加载插件` `Gmeek-load-plugins` 只需要加载  `Gmeek-load-plugins`  插件就可以避免该情况

多插件加载官方写法  

以下为3个简单插件加载方式
```json
"script":"<script src='https://blog.caicai.asia/GmeekUtils/GmeekTOC-20261106.js'></script><script src='https://blog.caicai.asia/GmeekUtils/GmeekButton-Top-Foot.20261107-row.js'></script><script src='https://blog.caicai.asia/GmeekUtils/Gmeek-Article-RSS-TOC-20261107.js'></script>"
```


整合写法
```json
"script":"<script src='https://blog.caicai.asia/plugins/Gmeek-load-plugins-20261107.js'></script>"
```

只需要简单维护一个 `PLUGIN_URLS` 插件列表就可以实现多插件动态加载

```js
var PLUGIN_URLS = [

        // 1. 左侧：基于 RSS 的文章导航
        LOAD_BASE_URL + 'Gmeek-Article-RSS-TOC-20261107.js',

        // 2. 右侧：文章目录 TOC
        LOAD_BASE_URL + 'GmeekTOC-20261107.js',

        // 3. 右下角：回到顶部/底部按钮 
        // GmeekButton-Top-Foot-row-20261107.js/GmeekButton-Top-Foot-column-20261107.js 只能选择加载其中一个
        LOAD_BASE_URL + 'GmeekButton-Top-Foot-row-20261107.js'

    ];
```
